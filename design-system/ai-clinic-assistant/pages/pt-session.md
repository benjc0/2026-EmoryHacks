# Page override — PT session (live camera)

Overrides MASTER for the live exercise screen only.

- **Dark stage, always** (regardless of theme): `#000` behind the video so the skeleton reads clearly. The HUD uses the dark-theme tokens.
- **Skeleton:** white 85% lines; the measured joint is drawn thick in light blue `#A6C8E2` (12.0 : 1 on black), or salmon `#FFB4A2` while a form rule is broken (with the rule spoken and shown as text). The angle label sits on a 60% black chip, ≥ 22 px.
- **Glanceable from 2 m:** the angle and rep count are ≥ 40 px; the coach line is ≥ 24 px bold. Spoken feedback carries the message, so patients never need to read mid-rep.
- **Progress bar** to target: 16 px tall, white target tick; the light-blue fill turns peach `#F4BAA3` when the target is reached (plus spoken cue, so it isn't color-only).
- **One action at a time:** setup shows only "Start now"; recording shows only "End". Both ≥ 48 px, top-right reachable with either thumb.
- **Status words with every color:** "✓ Good", "~ Fair: raise a little higher", "! Slow down".
- **Countdown** numerals 96 px; with reduced motion, no scale animation.
- **Precise mode (side arm raise only):** show "Right shoulder 128° · target 140°". **Simple mode (mini squat):** show reps and ✓/✗ only, no degrees.
